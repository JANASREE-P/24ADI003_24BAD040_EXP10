# 24ADI003_24BAD040_EXP10

SCENARIO 1:MATRIX FACTORIZATION USING SVD
DATASET:https://www.kaggle.com/datasets/abhikjha/movielens-100k
This project implements Singular Value Decomposition (SVD) to build a movie recommendation system. It reduces the dimensionality of the user-item matrix and predicts missing ratings using latent factors, enabling personalized recommendations.
SCENARIO 2:MATRIX FACTORIZATION USING NMF
DATASET:https://www.kaggle.com/datasets/abhikjha/movielens-100k
This project uses Non-negative Matrix Factorization (NMF) to generate recommendations based on interpretable latent features. The model decomposes the user-item matrix into non-negative factors, making it easier to understand user preferences and item characteristics.
